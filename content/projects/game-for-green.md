## The content is used for the description of the project
---

Borne by the need for increasing awareness of green behaviour and more responsible power consumption, the Game For Green project is a 2.5 million Euro project that designs, constructs and builds a game engine that supports serious game creation for companies, organisations and municipalities that wish to educate their employees, users and/or citizens for more responsible actions that align with green values. 
The project was sponsored by the Innovation Fund Denmark and started in May 2023.

My accomplishments in the project was to be the initial principal investigator (project manager) that wrote the application and ensured organising and facilitating the vision for the 8 collaborating contributors of the project: Roskilde University, Actee, Provice, Implement Group, HOFOR, Municipalities of Høje Taastrup, Vejle and Vallensbæk.

I have never been solely responsible for handling so many organisational actors with such a large amount of grant money, and it has truly been a learning experience on so many levels.
